# Documentation Archive

This directory stores completed, dated records that are not part of the current maintainer workflow.

## Collections

- `code-review/` contains historical source reviews, findings, plans, and review evidence.
- `migrations/` contains historical migration plans, coverage matrices, parity checks, and progress reports.

Do not use these collections as current specifications. Use them only when a task explicitly requires historical evidence or a comparison with an earlier implementation.

New current guidance must go under `docs/code-map/` or another clearly named current documentation directory. Do not add new work items to this archive.
