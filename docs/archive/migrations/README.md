# Archived Migration Records

These records describe completed or superseded migration work. They preserve decisions and evidence for historical reference.

## Reading Order

Read the numbered records in order:

1. `01-avalonia-rewrite-spec.md` defines the migration target.
2. `02-module-plans/` records the seven module boundaries.
3. `03-openspec-capability-split.md` maps the target to OpenSpec capabilities.
4. `04-coverage-matrix.md` records document and source coverage.
5. `05-implementation-progress-report.md` summarizes implementation status.
6. `06-spec-implementation-verification.md` records verification evidence and GUI checks.
7. `07-legacy-parity-and-retirement.md` records differences and the legacy retirement decision.
8. `08-avalonia-modernization-review.md` records the modernization review.
9. `09-browser-shared-ui-cutover-plan.md` records the browser shared-UI cutover plan.
10. `10-wasm-feature-parity-plan.md` records browser feature parity work.
11. `11-cli-host-extraction.md` records command-line host extraction.
12. `12-packaging-strategy.md` records packaging decisions.

The former `progress.md` content is now in `07-legacy-parity-and-retirement.md`. The former `gui-verification.md` content is now in `06-spec-implementation-verification.md`.

Use current source code, `docs/code-map/`, and OpenSpec specifications for present ownership and behavior.
