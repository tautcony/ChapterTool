## 审查维度

每个子代理按统一维度审查：

1. **正确性**：逻辑错误、边界条件、数值/时间计算错误、空引用。
2. **资源与并发**：IDisposable 泄漏、async/await 误用、线程安全、死锁风险。
3. **错误处理**：异常吞噬、错误传播缺失、用户可见错误的可诊断性。
4. **安全**：路径注入、进程参数注入、不可信输入解析（章节文件、MPLS/IFO 二进制等）。
5. **API 与架构**：分层越界、职责不清、依赖方向、与 AGENTS.md 约束的符合性。
6. **性能**：明显的算法/分配问题（仅报告有实际影响的）。
7. **本地化与编码**：中文字符串 UTF-8 有效性、本地化边界。

## 严重级别定义

- **高**：可导致数据损坏、崩溃、安全问题或明显功能错误。
- **中**：特定条件下的错误行为、资源泄漏、维护性风险。
- **低**：代码质量、一致性、可读性问题。
